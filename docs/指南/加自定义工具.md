# 加自定义工具

> 定义工具 Schema → 实现 handler → 注册到 EngineHandle → 验证。

## 1. 定义工具 Schema

工具定义遵循 OpenAI Function Calling 格式：

```rust
let schema = serde_json::json!({
    "type": "function",
    "function": {
        "name": "get_weather",
        "description": "查询指定城市的天气",
        "parameters": {
            "type": "object",
            "properties": {
                "city": { "type": "string", "description": "城市名" }
            },
            "required": ["city"]
        }
    }
});
```

## 2. 实现 handler

handler 接收 LLM 的 JSON 参数 + 框架注入的 ToolCallContext，返回 JSON 字符串：

```rust
use std::sync::Arc;
use fuyao_api::ToolFn;

let handler: ToolFn = Arc::new(|args, _ctx| {
    Box::pin(async move {
        let city = args["city"].as_str().unwrap_or("unknown");
        format!(r#"{{"result": "{} 晴天 25°C"}}"#, city)
    })
});
```

## 3. 注册

```rust
handle.register_tool("get_weather", schema, handler);
```

在 `init_engine` 之后、`setup` 之前注册（分步装配的第二步），或 `start` 之后注册。

## 验证

```rust
handle.send_message("北京天气怎么样？".to_string()).await;
// 观察事件流：ToolCall(tool_name="get_weather") → ToolResult
```
