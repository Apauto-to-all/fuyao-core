# 配置日志输出

> fuyao.toml 的 `[logging]` 段 + RUST_LOG 环境变量。

## 基本配置

```toml
[logging]
level = "info"        # 全局级别
console = true        # stderr 彩色输出（文件层始终输出）
rotation = "daily"    # daily | hourly | never
```

## level 语法（EnvFilter）

level 支持 EnvFilter 指令语法，可按 crate 调级别：

```toml
level = "info"                                # 全局 info
level = "debug"                               # 全局 debug
level = "info,fuyao_provider=warn"            # 全局 info，provider 降到 warn
level = "fuyao_core=debug,fuyao_session=trace" # 指定 crate 级别
```

## RUST_LOG 覆盖

运行时用环境变量覆盖配置文件：

```bash
RUST_LOG=debug cargo run
RUST_LOG="fuyao_core=trace" cargo run
```

RUST_LOG 优先级高于 fuyao.toml 的 level。

## 日志文件位置

per-agent 隔离（见 [Agent 身份与路径设计](../解释/Agent身份与路径设计.md)）：

| 条件 | 日志目录 |
|------|---------|
| 有 agent_id | `{agent_root}/logs/` |
| 无 agent_id | `~/.fuyao/logs/` |

LogGuard 由 AppContext 持有，drop 时 flush 剩余日志。
