# 分步装配引擎

> 一行启动用 `fuyao_app::start`；需要介入注册流程时分步装配。

## 前置条件

- fuyao.toml 配好 Provider + Model（见 [配置项参考](../参考/配置项参考.md)）
- .env 配好 API Key
- 构造好 AgentContext（见 [Agent 身份与路径设计](../解释/Agent身份与路径设计.md)）

## 一行启动

```rust
let (engine, handle, app_ctx) = fuyao_app::start(agent_ctx).await?;
```

内部完成：init_engine + setup（注册工具 + MCP + 插件 + 日志）。

## 分步装配

### 1. init_engine — 加载配置 → 注册 Provider → 装配 Engine

```rust
let (engine, handle, log_guard) = fuyao_app::init_engine(agent_ctx)?;
```

完成：load_env + load_config → 注册 Provider / Model → init_logging → Engine::new

### 2. 介入点 — 可在此注册自定义工具、调整配置

```rust
// 示例：在 setup 前注册自定义工具
handle.register_tool("my_tool", schema, handler);
```

### 3. setup — 注册内置工具 + MCP + 插件

```rust
let app_ctx = fuyao_app::setup(&handle).await?;
```

完成：register_builtin_tools（按 `[tools.enabled]` 过滤）→ register_mcp_tools → 构造 SessionPlugin / LoopGuardPlugin → PluginHost::install

app_ctx 持有 MCPManager、PluginHost、LogGuard。

## 验证

```rust
handle.send_message("你好".to_string()).await;
while let Some(event) = handle.next_event().await {
    match event {
        OutputEvent::Chunk(c) => { if let Some(t) = c.content { print!("{}", t); } }
        OutputEvent::Assistant(_) => break,
        _ => {}
    }
}
```
