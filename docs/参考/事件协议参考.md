# 事件协议参考

> InputEvent / OutputEvent 全变体与字段参考。API 签名见 `cargo doc --workspace`。
>
> **结构约定**：每个事件采用 envelope + payload 两层——envelope（`XxxMessage`）含 `base` 字段，payload（`XxxPayload`）含业务字段。下文逐事件列出全部字段（base + payload 平铺）。

## 事件基座 EventBase

所有事件内嵌 `base` 字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `String` | 事件唯一 ID（UUID v4） |
| `timestamp` | `f64` | 事件时间戳（Unix 纪元秒） |

## InputEvent（应用层 → Engine）

4 个变体，JSON 序列化带 `type` 鉴别字段。

### User — 用户消息

| 字段 | 类型 | 说明 |
|------|------|------|
| `base` | `EventBase` | 事件元信息 |
| `content` | `String` | 消息文本内容 |
| `mode` | `UserMessageMode` | 消息模式（默认 `Guide`） |
| `source` | `UserMessageSource` | 消息来源（默认 `User`） |

用户在界面发送消息时携带；也可用于系统注入（超时提醒、错误恢复）或插件注入（循环检测后注入引导消息），由 `source` 区分。

### Interrupt — 中断

| 字段 | 类型 | 说明 |
|------|------|------|
| `base` | `EventBase` | 事件元信息 |
| `reason` | `String` | 中断原因描述 |
| `source` | `InterruptSource` | 中断来源 |

用户、钩子、系统所有中断路径统一走此变体。中断是纯停止信号，不耦合注入消息；如需中断后注入引导消息，额外发送 `User`。

### Shutdown — 关闭引擎

| 字段 | 类型 | 说明 |
|------|------|------|
| `base` | `EventBase` | 事件元信息 |

### Plugin — 插件通知

| 字段 | 类型 | 说明 |
|------|------|------|
| `base` | `EventBase` | 事件元信息 |
| `source` | `PluginEventSource` | 来源插件 |
| `event_type` | `String` | 事件类型（插件自定义字符串标识） |
| `data` | `Option<serde_json::Value>` | 事件数据（任意 JSON，引擎不解析透传） |
| `error` | `Option<String>` | 错误信息 |
| `message` | `Option<String>` | 提醒信息 |

插件通过 `SendInputFn` 钩子发送通知；引擎接收后转发为 `OutputEvent::Plugin`。

## OutputEvent（Engine → 应用层）

10 个变体。

### TurnStart — 轮次开始

| 字段 | 类型 | 说明 |
|------|------|------|
| `base` | `EventBase` | 事件元信息 |

引擎每次 ReAct 轮次开始时发出。

### Chunk — 流式输出块

| 字段 | 类型 | 说明 |
|------|------|------|
| `base` | `EventBase` | 事件元信息 |
| `content` | `Option<String>` | 文本片段（增量） |
| `reasoning` | `Option<String>` | 推理片段（增量） |

LLM 流式输出时，每个文本 / 推理片段作为一个 Chunk 推送。两字段可同时为 `None`、同时为 `Some`、或任一为 `Some`。

### User — 用户消息回显

| 字段 | 类型 | 说明 |
|------|------|------|
| `base` | `EventBase` | 事件元信息 |
| `content` | `String` | 消息文本内容 |
| `mode` | `UserMessageMode` | 消息模式 |
| `source` | `UserMessageSource` | 消息来源 |

引擎处理用户输入后发出，确保引擎处理的内容与 UI 显示的一致。

### ToolCall — 工具调用

| 字段 | 类型 | 说明 |
|------|------|------|
| `base` | `EventBase` | 事件元信息 |
| `tool_call_id` | `String` | 工具调用 ID |
| `tool_name` | `String` | 工具名称 |
| `tool_args` | `serde_json::Value` | 工具参数（JSON 对象，可为空 `{}`） |

LLM 决定调用工具时推送。

### ToolResult — 工具结果

| 字段 | 类型 | 说明 |
|------|------|------|
| `base` | `EventBase` | 事件元信息 |
| `tool_call_id` | `String` | 工具调用 ID（与对应 ToolCall 配对） |
| `tool_name` | `String` | 工具名称 |
| `content` | `String` | 工具结果内容 |

工具执行完成后推送。

### Assistant — 助手消息完成

| 字段 | 类型 | 说明 |
|------|------|------|
| `base` | `EventBase` | 事件元信息 |
| `content` | `Option<String>` | 消息内容 |
| `reasoning` | `Option<String>` | 推理内容 |
| `tool_calls` | `Option<Vec<ToolCallPayload>>` | 工具调用列表 |
| `finish_reason` | `Option<String>` | 完成原因：`stop` / `tool_calls` / `length` / `content_filter` |
| `completion_tokens` | `i64` | 输出令牌数 |
| `prompt_tokens` | `i64` | 提示词令牌数 |
| `total_tokens` | `i64` | 总令牌数 |
| `reasoning_tokens` | `i64` | 推理令牌数 |
| `cached_tokens` | `i64` | 缓存命中令牌数 |

AI 完整输出一条消息时推送，包含内容、推理、工具调用、用量等全部信息。

### Interrupt — 中断

| 字段 | 类型 | 说明 |
|------|------|------|
| `base` | `EventBase` | 事件元信息 |
| `reason` | `String` | 中断原因 |
| `source` | `InterruptSource` | 中断来源 |

引擎中断轮次后发出。所有中断通知统一走此变体。

### Error — 错误

| 字段 | 类型 | 说明 |
|------|------|------|
| `base` | `EventBase` | 事件元信息 |
| `message` | `String` | 错误消息 |
| `recoverable` | `bool` | 是否可恢复（UI 可提示继续） |

### Plugin — 插件事件

| 字段 | 类型 | 说明 |
|------|------|------|
| `base` | `EventBase` | 事件元信息 |
| `source` | `PluginEventSource` | 来源插件 |
| `event_type` | `String` | 事件类型（插件自定义字符串标识） |
| `data` | `Option<serde_json::Value>` | 事件数据（任意 JSON，透传） |
| `error` | `Option<String>` | 错误信息 |
| `message` | `Option<String>` | 提醒信息 |

由引擎从 `InputEvent::Plugin` 转发，或插件主动 emit。

### QueueUpdate — 队列状态更新

| 字段 | 类型 | 说明 |
|------|------|------|
| `base` | `EventBase` | 事件元信息 |
| `guide_count` | `usize` | 引导队列当前长度 |
| `pending_count` | `usize` | 排队队列当前长度 |
| `kind` | `QueueUpdateKind` | 变化种类 |

双队列（guide / pending）机制的状态通知。携带当前队列长度快照（非增量），UI 即使丢失中间事件也能恢复正确状态。

`base.id` 复用语义：`Enqueued` / `Consumed` 复用对应 `UserMessage` 的 `base.id`，便于 UI 精确配对；`Transferred` 用默认值。

## 共享枚举

### InterruptSource

| 变体 | 说明 |
|------|------|
| `User` | 用户主动中断 |
| `Hook` | 钩子拦截中断（循环检测等） |
| `System` | 系统中断（超时、错误等） |

### UserMessageMode

| 变体 | 说明 |
|------|------|
| `Guide` | 引导模式：进入引导队列，AI 完成一轮对话后立即投递（默认） |
| `Pending` | 排队模式：进入排队队列，等待 AI 不再调用工具后才投递 |

### UserMessageSource

| 变体 | 载荷 | 说明 |
|------|------|------|
| `User` | 无 | 用户主动输入 |
| `System(SystemSource)` | `{ reason: String }` | 系统注入（超时提醒等） |
| `Plugin(PluginSource)` | `{ name: String }` | 插件注入（循环检测后注入引导消息等） |

### QueueUpdateKind

| 变体 | 说明 |
|------|------|
| `Enqueued` | 用户消息入队（guide 或 pending） |
| `Consumed` | TurnExecutor 消费一条 guide 消息 |
| `Transferred` | pending 全部转移到 guide |

### PluginEventSource

| 字段 | 类型 | 说明 |
|------|------|------|
| `name` | `String` | 插件标识 |
