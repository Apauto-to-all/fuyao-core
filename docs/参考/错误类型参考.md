# 错误类型参考

> 16 个 Error 类型的变体与触发条件。API 签名见 `cargo doc --workspace`。

> 所有 Error 类型均使用 `thiserror` 派生，均实现 `Send + Sync`，均未实现 `Clone`。

## fuyao-api

### ApiError

| 变体 | 触发场景 |
|------|---------|
| `RequestFailed(String)` | HTTP 请求失败 |
| `ModelNotFound { model }` | 模型在注册表中查不到 |
| `ParseError(serde_json::Error)` | JSON 序列化/反序列化失败 |
| `ConfigError(String)` | 配置相关错误 |
| `SessionNotFound(String)` | 会话 ID 查无 |
| `ToolError { tool, reason }` | 工具调用失败 |
| `IoError(std::io::Error)` | 文件 IO 失败 |

### ConfigError

| 变体 | 触发场景 |
|------|---------|
| `IoError(std::io::Error)` | 配置文件读取失败 |
| `TomlError(toml::de::Error)` | TOML 解析/反序列化失败 |
| `FileNotFound(String)` | 配置文件不存在 |

## fuyao-provider

### StreamError（运行时）

| 变体 | 触发场景 | 可重试 |
|------|---------|--------|
| `ApiError(String)` | HTTP 5xx 等 | 视内容 |
| `StreamParseError(String)` | SSE 解析失败 | 否 |
| `Timeout` | 请求超时 | 是 |
| `AuthError(String)` | HTTP 401/403 | 否 |
| `RateLimit { retry_after_ms, retry_after_secs }` | HTTP 429 | 是 |
| `Connection(String)` | 网络连接失败 | 是 |
| `ContextOverflow` | token 超限 | 否 |

### ProviderError（注册表）

| 变体 | 触发场景 |
|------|---------|
| `ProviderNotFound(String)` | provider_id 查无 |
| `MissingApiKey { provider }` | API Key 未配置 |
| `ModelNotFound(String)` | 模型查无 |
| `InvalidModelId(String)` | 模型 ID 格式错误（缺 `/`） |

### ClientError

| 变体 | 触发场景 |
|------|---------|
| `InvalidModelId(String)` | `parse_model_id` 解析失败 |

## fuyao-mcp

### MCPManagerError

| 变体 | 触发场景 |
|------|---------|
| `ServerNotFound(String)` | server 查无 |
| `ServerNotConnected(String)` | 连接已断开 |
| `ServerStartFailed { server, reason }` | 启动失败 |
| `ToolNotFound { server, tool }` | 工具查无 |
| `CallFailed(String)` | 调用失败（含脱敏） |

### ConnectionError

| 变体 | 触发场景 |
|------|---------|
| `NotConnected { server }` | 操作时连接已断 |
| `InitialConnectFailed { server, reason }` | 首次连接失败 |
| `ConnectTimeout { server }` | 连接超时 |
| `MissingCommand` | stdio 缺 `command` |
| `MissingUrl` | HTTP 缺 `url` |
| `CallFailed(String)` | RPC 调用失败 |

## fuyao-skills

### SkillsError

| 变体 | 触发场景 |
|------|---------|
| `Io(std::io::Error)` | Skill 文件读取失败 |
| `Yaml(serde_yaml::Error)` | frontmatter YAML 解析失败 |
| `NotFound(String)` | Skill 不存在 |
| `PathTraversal(String)` | 路径遍历攻击拦截 |

## fuyao-hooks

### PluginInstallError

| 变体 | 触发场景 |
|------|---------|
| `DuplicateName { name }` | 插件重名（硬失败） |

## fuyao-prompt

### PromptError

| 变体 | 触发场景 |
|------|---------|
| `Io(std::io::Error)` | Prompt 文件读取失败 |
| `Yaml(serde_yaml::Error)` | frontmatter YAML 解析失败 |

### RegistryError

| 变体 | 触发场景 |
|------|---------|
| `InvalidName(String)` | 名称含非法字符/保留名 |
| `NotFound(String)` | Agent 文件夹不存在 |
| `AlreadyExists(String)` | 创建时同名冲突 |
| `DefaultForbidden` | default Agent 禁止编辑/删除 |
| `WorkspaceMissing` | 未配置工作目录 |
| `Io(std::io::Error)` | 文件读写失败 |

## fuyao-session

### SessionError

| 变体 | 触发场景 |
|------|---------|
| `Database(String)` | SQLite 操作失败 |
| `IoError(std::io::Error)` | 文件 IO 失败 |
| `SqlxError(sqlx::Error)` | sqlx 底层错误 |
| `InvalidState(String)` | SessionManager 未初始化 |
| `NotFound(String)` | 会话查无 |

## fuyao-tools

### ToolError

| 变体 | 触发场景 |
|------|---------|
| `FileNotFound(String)` | 文件不存在 |
| `NotAFile(String)` | 路径指向目录 |
| `PermissionDenied(String)` | 权限不足 |
| `BinaryFile(String)` | 二进制文件 |
| `ContentTooLarge { actual, max }` | 超出字符上限 |
| `EmptyPath` | 路径为空 |
| `SensitivePath(String)` | 敏感路径拒绝 |
| `IoError(std::io::Error)` | IO 错误 |

## fuyao-app

### InitError（init_engine 返回）

| 变体 | 触发场景 |
|------|---------|
| `NoModelWithDetail { model_id, available }` | 未配置 model_id 且注册表为空 |
| `ProviderNotFoundWithDetail { provider_id, available_providers }` | Provider 创建失败（API Key 缺失等） |
| `ModelInfoFailed(String)` | 模型信息获取失败 |
| `ConfigError(String)` | 配置加载失败 |

### SetupError（setup / start 返回）

| 变体 | 触发场景 |
|------|---------|
| `NoAgentContext` | 缺少 AgentContext |
| `Init(InitError)` | 引擎初始化失败（透传） |
| `PluginInstall(PluginInstallError)` | 插件装配失败（透传） |

## 错误转换链

```text
SetupError（顶层聚合）
  ├── Init(InitError)           ← init_engine 失败
  │     ├── ConfigError(String) ← 吸收 ConfigError（丢失类型）
  │     └── ProviderNotFound    ← 吸收 ProviderError
  └── PluginInstall(PluginInstallError)
        └── DuplicateName       ← 插件重名
```
