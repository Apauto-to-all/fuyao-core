# 错误类型参考

> fuyao-core 所有 `Error` 类型的变体与触发条件。字段与签名见 `cargo doc --workspace`。
>
> 所有 Error 类型均使用 `thiserror` 派生，均实现 `Send + Sync`，均未实现 `Clone`。

## fuyao-api

### ApiError

| 变体 | 触发场景 |
|------|---------|
| `RequestFailed(String)` | HTTP 请求失败 |
| `ModelNotFound { model }` | 模型在注册表中查不到 |
| `ParseError(serde_json::Error)` | JSON 序列化/反序列化失败 |
| `ConfigError(String)` | 配置相关错误 |
| `SessionNotFound(String)` | 会话 ID 查无 |
| `ToolError { tool, reason }` | 工具调用失败 |
| `IoError(std::io::Error)` | 文件 IO 失败 |

### ConfigError

| 变体 | 触发场景 |
|------|---------|
| `IoError(std::io::Error)` | 配置文件读取失败 |
| `TomlError(toml::de::Error)` | TOML 解析/反序列化失败 |
| `FileNotFound(String)` | 配置文件不存在 |

## fuyao-provider

### StreamError（运行时）

| 变体 | 触发场景 | 可重试 |
|------|---------|--------|
| `ApiError(String)` | HTTP 5xx 等 | 视内容 |
| `StreamParseError(String)` | SSE 解析失败 | 否 |
| `Timeout` | 请求超时 | 是 |
| `AuthError(String)` | HTTP 401/403 | 否 |
| `RateLimit { retry_after_ms, retry_after_secs }` | HTTP 429 | 是 |
| `Connection(String)` | 网络连接失败 | 是 |
| `ContextOverflow` | token 超限（HTTP 413） | 否 |
| `Cancelled` | 操作被取消（引擎 shutdown 触发，**非错误**） | 否（`is_retryable(Cancelled) = false`） |

> `Cancelled` 由 `RetryRunner` 在退避 sleep 期间收到 `shutdown_token` 信号时产生，冒泡到 `turn.rs` 后由 shutdown 分支走中断路径（不发 Error 事件）。

### ProviderError（注册表）

| 变体 | 触发场景 |
|------|---------|
| `ProviderNotFound(String)` | provider_id 查无 |
| `MissingApiKey { provider }` | API Key 未配置 |
| `ModelNotFound(String)` | 模型查无 |
| `InvalidModelId(String)` | 模型 ID 格式错误（缺 `/`） |

### ClientError

| 变体 | 触发场景 |
|------|---------|
| `InvalidModelId(String)` | `parse_model_id` 解析失败 |

## fuyao-prompt

### PromptError

Agent 定义解析错误（`resolve_definition` 产生，定义名必填、不做静默人格替换）。

| 变体 | 触发场景 |
|------|---------|
| `DefinitionNotFound { name, available }` | 定义名在四层目录与内置表均未命中；`available` 为按用途过滤的可用名列表（顿号分隔） |
| `ModeMismatch { name, mode, usage }` | 定义存在，但 mode 与请求用途不符（如 Subagent 定义用作会话人格） |

### RegistryError

| 变体 | 触发场景 |
|------|---------|
| `InvalidName(String)` | 名称含非法字符/保留名 |
| `NotFound(String)` | Agent 文件夹不存在 |
| `AlreadyExists(String)` | 创建时同名冲突 |
| `DefaultForbidden` | default Agent 禁止编辑/删除 |
| `WorkspaceMissing` | 未配置工作目录 |
| `Io(std::io::Error)` | 文件读写失败 |

## fuyao-session

### SessionError

| 变体 | 触发场景 |
|------|---------|
| `IoError(std::io::Error)` | 文件 IO 失败 |
| `SqlxError(sqlx::Error)` | sqlx 底层错误 |
| `InvalidState(String)` | SessionStore 未初始化等状态错误 |
| `NotFound(String)` | 会话查无（resume 时 id 在 DB 不存在；`end_session` 时 id 在 DB 不存在） |

## fuyao-core

### EngineError

| 变体 | 触发场景 |
|------|---------|
| `SessionNotFound(String)` | session id 不在调度表（send / end_session 时查无） |
| `Storage(SessionError)` | 存储层错误（`#[from]` 从 SessionError 转换） |
| `Provider(String)` | 提供者（LLM）错误，用于装配或同步调用失败 |
| `Prompt(PromptError)` | Agent 定义解析错误（`#[from]` 从 PromptError 转换；创建 / 恢复 / 派生会话时 definition 未知名或 mode 与用途不符） |
| `Shutdown` | 引擎已 shutdown（send / end_session 立即返回此错误；recv 返回 None） |

> 这是「同步校验错误」——调用函数瞬间即可判断，走 `Err` 返回。异步执行错误（LLM 失败、工具出错等）走 `OutputEvent::Error` 事件流，不在本枚举中。

## fuyao-app

### InitError（init_engine 返回）

| 变体 | 触发场景 |
|------|---------|
| `NoProviderAvailable` | 所有 Provider 实例创建失败（注册表为空或 API Key 都未配置） |
| `ConfigError(String)` | 配置加载失败（TOML 解析错误、IO 错误等） |

### SetupError（start 返回）

| 变体 | 触发场景 |
|------|---------|
| `Init(InitError)` | 引擎初始化失败（透传） |

## 错误转换链

```text
SetupError（顶层聚合）
  └── Init(InitError)            ← init_engine 失败
        ├── NoProviderAvailable  ← 所有 Provider 实例创建失败
        └── ConfigError(String)  ← 配置加载失败

EngineError（同步校验错误）
  ├── SessionNotFound(String)    ← session id 不在调度表
  ├── Storage(SessionError)      ← 存储层错误
  ├── Provider(String)           ← 提供者错误
  ├── Prompt(PromptError)        ← Agent 定义未知名 / mode 与用途不符
  │     ├── DefinitionNotFound   ← 四层目录与内置表均未命中（附可用列表）
  │     └── ModeMismatch         ← mode 与请求用途不符
  └── Shutdown                   ← 引擎已关闭

StreamError（LLM 调用运行时错误，由 RetryRunner 决定发 Retry 还是 Error 事件）
  ├── 可重试（RateLimit / Timeout / Connection / 5xx ApiError）→ OutputEvent::Retry
  ├── 不可重试（AuthError / 4xx ApiError / StreamParseError / ContextOverflow）→ OutputEvent::Error
  └── Cancelled（shutdown 触发）→ OutputEvent::Interrupt(Shutdown)
```
