# 配置项参考

> fuyao.toml 全字段参考。API 签名见 `cargo doc --workspace`。
>
> **配置写法约定**（内联表精简、冗余 `[xxx]` 避免等）见 [`docs/指南/TOML格式约定.md`](../指南/TOML格式约定.md)。

## 文件位置与合并

fuyao.toml 按三层路径加载，优先级从低到高：

| 层 | 路径 |
| ---- | ------ |
| 全局 | `~/.fuyao/fuyao.toml` |
| Agent | `{agent_root}/fuyao.toml` |
| 工作区 | `{workspace}/.fuyao/fuyao.toml` |

同名 `.env` 文件按相同三层加载，高优先级覆盖低优先级。

**合并规则**：嵌套 table 递归合并（字段级）；scalar / array 整体覆盖；缺失段回退各自 Default。

| 键 | 类型 | 默认 | 说明 |
| ---- | ------ | ------ | ------ |
| `[models.*]` | table | — | 多模型选择（按用途标签，如 `default` / `fast`） |
| `[providers.*]` | table | — | 供应商配置 |
| `[mcp_servers.*]` | table | — | MCP Server 配置 |
| `[tools]` | table | default | 工具系统 |
| `[guard]` | table | default | 行为防护 |
| `[llm]` | table | default | LLM 调用 |
| `[image]` | table | default | 图片处理（入站节流 / token 估算） |
| `[session]` | table | default | 会话 |
| `[mcp]` | table | default | MCP 全局 fallback |
| `[engine]` | table | default | 引擎通道 |
| `[hooks]` | table | default | 钩子 |
| `[plugins]` | table | default | 插件 |
| `[logging]` | table | default | 日志 |

## [models.*]

多模型选择配置。标签固定为 `default` / `fast`，每个标签配置一个模型引用。
引擎与各模块按标签选取模型，实现主对话用强模型、轻量任务用便宜模型的区分。
未知标签会加载报错，避免配了不生效的死配置。

| 键 | 类型 | 默认 | 说明 |
|----|------|------|------|
| `model` | `String` | — | 模型 ID，格式 `provider_id/model_id`（如 `deepseek/deepseek-v4-flash`） |
| `thinking_type` | `"enabled"` / `"disabled"` | — | 思考开关（对应请求体 `thinking.type`）。缺省不发，走模型自身默认 |
| `reasoning_effort` | `String` | — | 思考强度档位名（用户自定义字符串，透传给服务器）。缺省不发，走模型自身默认 |

`default` 与 `fast` 共用同一结构，均支持全部 3 字段。三字段均可选：缺省即不发，走模型自身默认行为。

内置标签：

| 标签 | 用途 |
|------|------|
| `default` | 默认模型（主对话）。未显式指定 model_id 时使用 |
| `fast` | 轻量任务模型（标题生成等），便宜快速 |

## [providers.*]

每个 key 是供应商 ID（如 `deepseek`、`aliyun`），用于 `[models.*]` 的 `model = "{provider_id}/{model_id}"` 引用。

| 键 | 类型 | 必填 | 默认 | 说明 |
| ---- | ------ | ------ | ------ | ------ |
| `name` | `String` | 是 | — | 供应商显示名称；缺失则整个 Provider 被跳过 |
| `api_key_env_vars` | `[String]` | 否 | `[]` | API Key 环境变量名列表 |
| `options` | table | 否 | default | 连接选项 |
| `models` | table | 否 | `{}` | 模型字典，key=模型 ID |

### [providers.*.options]

| 键 | 类型 | 默认 | 说明 |
|----|------|------|------|
| `base_url` | `String` | — | 自定义 API base URL |
| `api_key` | `String` | — | 直接配置 API Key（也可用 `api_key_env_vars`） |

### [providers.*.models.<id>]

| 键 | 类型 | 必填 | 默认 | 说明 |
| ---- | ------ | ------ | ------ | ------ |
| `name` | `String` | 是 | — | 模型显示名；缺失则模型被跳过 |
| `reasoning_efforts` | `[String]` | 否 | `[]` | 思考强度档位（如 `["low","medium","high","max"]`） |
| `cost` | table | 否 | default | 价格信息 |
| `limit` | table | 否 | default | 限制信息 |
| `modalities` | table | 否 | default | 模态支持 |

### [providers.*.models.<id>.cost]

| 键 | 类型 | 默认 | 说明 |
| ---- | ------ | ------ | ------ |
| `input` | `f64` | — | 输入价格（/M tokens；整数或浮点均可） |
| `output` | `f64` | — | 输出价格 |
| `reasoning` | `f64` | — | 推理价格 |
| `cache` | `f64` | — | 缓存价格 |
| `tiers` | array | `[]` | 梯度价格区间 |

#### [[providers.*.models.<id>.cost.tiers]]

| 键 | 类型 | 必填 | 说明 |
| ---- | ------ | ------ | ------ |
| `max_tokens` | `u32` | 是 | 区间上限；缺失则该 tier 被丢弃 |
| `input` | `f64` | 否 | 该区间输入价格 |
| `output` | `f64` | 否 | 该区间输出价格 |
| `reasoning` | `f64` | 否 | 该区间推理价格 |
| `cache` | `f64` | 否 | 该区间缓存价格 |

### [providers.*.models.<id>.limit]

| 键 | 类型 | 默认 | 说明 |
| ---- | ------ | ------ | ------ |
| `context` | `u32` | `0` | 最大上下文窗口（tokens） |
| `input` | `u32` | — | 最大输入 tokens |
| `output` | `u32` | `0` | 最大输出 tokens |

### [providers.*.models.<id>.modalities]

| 键 | 类型 | 默认 | 说明 |
|----|------|------|------|
| `input` | `[String]` | `["text"]` | 输入模态。`"text"` 为纯文本；含 `"image"` 表示模型支持图片输入——用户消息可携带图片附件，引擎会发送图像给该模型 |
| `output` | `[String]` | `["text"]` | 输出模态 |

未声明 `modalities`（或声明中不含 `"image"`）的模型按**不支持图片**处理：用户消息携带图片时，图片被省略、消息文本附加占位提示（对话继续，不失败）。

## [mcp_servers.*]

每个 key 是 Server 名称。传输类型由字段判定：有 `url` → HTTP，有 `command` → stdio。所有 string 值支持 `${VAR}` 环境变量插值。

| 键 | 类型 | 默认 | 说明 |
| ---- | ------ | ------ | ------ |
| `command` | `String` | — | stdio 传输：启动命令 |
| `args` | `[String]` | — | stdio 传输：命令参数 |
| `env` | table | — | stdio 传输：环境变量 |
| `url` | `String` | — | HTTP 传输：endpoint URL |
| `headers` | table | — | HTTP 传输：请求头 |
| `enabled` | `bool` | `true` | Server 级总开关；`false` 时跳过启动（不连接、不发现工具） |
| `timeout` | `u32` | `120` | 工具调用超时（秒） |
| `connect_timeout` | `u32` | `60` | 连接超时（秒） |
| `tools` | table | `{}` | 工具开关；未列出默认启用 |

## [tools]

| 键 | 类型 | 默认 | 说明 |
| ---- | ------ | ------ | ------ |
| `enabled` | table | `{}` | 全局工具开关，key=工具名；在注册漏斗统一生效，覆盖所有工具来源（内置 / MCP / 插件）；未列出默认启用，显式 `false` 禁用。MCP 工具因有 `mcp_server_tool` 前缀，通常改用 `[mcp_servers.<name>.tools]` 按单 server 控制粒度。**定义层**（`agents/*.md` frontmatter）也有同款 `tools` 字段做 per-session 收窄，与全局取交集（全局禁用是最高优先级硬约束）；未知名（拼错 / 已卸载）统一静默忽略 + WARN |
| `runner` | table | default | 并发策略 |
| `limits` | table | default | 高频可调限制 |

### [tools.runner]

| 键 | 类型 | 默认 | 说明 |
| ---- | ------ | ------ | ------ |
| `max_concurrent` | `u32` | `8` | 最大并发工具数 |
| `never_parallel` | `[String]` | `["bash","todowrite"]` | 强制串行工具 |
| `parallel_safe` | `[String]` | `["read","glob","grep","skill","webfetch","subagent"]` | 只读 / 独立可并行工具（subagent 派生独立 child session，无共享状态） |
| `path_scoped` | `[String]` | `["read","write","edit"]` | 文件工具（先检查路径重叠） |

> 判定顺序：`never_parallel` → `path_scoped`（检查路径重叠）→ `parallel_safe`

### [tools.limits]

| 键 | 类型 | 默认 | 说明 |
| ---- | ------ | ------ | ------ |
| `search_timeout_secs` | `u64` | `60` | 搜索命令超时（秒） |
| `terminal_default_timeout_secs` | `u64` | `120` | 默认终端超时（秒） |
| `terminal_max_timeout_secs` | `u64` | `6000` | 最大终端超时（秒） |
| `terminal_max_output_chars` | `usize` | `50000` | 最大终端输出字符数 |
| `webfetch_default_timeout_secs` | `u64` | `30` | 默认 WebFetch 超时（秒） |
| `webfetch_max_timeout_secs` | `u64` | `180` | 最大 WebFetch 超时（秒） |
| `webfetch_max_output_chars` | `usize` | `100000` | 最大 WebFetch 输出字符数 |
| `webfetch_max_download_bytes` | `usize` | `5242880`（5MB） | 最大 WebFetch 下载字节数 |

| 键 | 类型 | 默认 | 说明 |
| ---- | ------ | ------ | ------ |
| `tool_repeat_threshold` | `usize` | `4` | 连续 N 次相同操作触发警告 |
| `tool_alternate_threshold` | `usize` | `6` | A↔B 交替循环检测窗口 |

## [llm]

| 键 | 类型 | 默认 | 说明 |
| ---- | ------ | ------ | ------ |
| `request_timeout_secs` | `u64` | `300` | HTTP 请求超时（秒） |
| `connect_timeout_secs` | `u64` | `10` | HTTP 连接超时（秒） |
| `retry` | table | default | 退避策略 |

### [llm.retry]

| 键 | 类型 | 默认 | 说明 |
| ---- | ------ | ------ | ------ |
| `initial_delay_ms` | `u64` | `2000` | 退避起始延迟（毫秒） |
| `max_delay_ms` | `u64` | `30000` | 无响应头时退避上限（毫秒） |
| `max_delay_with_headers_ms` | `u64` | `2147483647` | 有响应头时退避上限（毫秒） |
| `max_retries` | `u32` | `4294967295`（`u32::MAX`，无限重试） | 可恢复错误（RateLimit / Timeout / Connection / 5xx）的最大重试次数；严重错误（Auth / 4xx / ContextOverflow）不受此字段控制，一律 0 次重试立即冒泡 |

## [image]

图片入站节流策略。消息内嵌图片的处理参数集中于此。
协议侧硬约束（如 OpenAI 的 MIME 白名单、20MB 协议上限）属供应商协议事实，不在此配置。

| 键 | 类型 | 默认 | 说明 |
|----|------|------|------|
| `compress` | `bool` | `true` | 超限图片是否压缩节流；`false` 时超限图原样落库（仍做 data URL 归一），存储膨胀与发送超限风险由用户自负 |
| `max_pixels` | `u32` | `2000` | 入站节流：图片最大边长（像素），超限等比缩放 |
| `max_base64_bytes` | `usize` | `5242880`（5MB） | 入站节流：base64 字节上限，超限触发解码 + 压缩 |
| `jpeg_qualities` | `[u8]` | `[85,80,70,55,40]` | 入站节流：JPEG 压缩质量档位（降序尝试，首个达标即用） |

## [session]

| 键 | 类型 | 默认 | 说明 |
| ---- | ------ | ------ | ------ |
| `compression` | table | default | 上下文压缩 |
| `storage` | table | default | SQLite 存储 |
| `title` | table | default | 标题自动生成 |

### [session.compression]

| 键 | 类型 | 默认 | 说明 |
| ---- | ------ | ------ | ------ |
| `enabled` | `bool` | `true` | 是否启用上下文压缩 |
| `threshold` | `f64` | `0.85` | 触发阈值（0.0~1.0），`prompt_tokens / (context_length - summary_max_tokens)` 超过此值触发 |
| `keep_ratio` | `f64` | `0.05` | 保留窗口的相对比例，实际保留 = `min(context_length × keep_ratio, keep_tokens_max)` |
| `keep_tokens_max` | `usize` | `8000` | 保留窗口的 token 上限（防超长上下文模型保留过多） |
| `summary_max_tokens` | `usize` | `4096` | 摘要 LLM 输出上限（token），也作为触发公式中的输出预留扣除 |
| `fallback_context` | `u32` | `128000` | 无法解析模型上下文长度时的回退值 |
| `tokens_per_image` | `usize` | `1000` | 压缩 token 估算：每张图固定占用 token（不按 base64 字符数估算，避免撑爆触发误压缩） |
| `skip_child` | `bool` | `true` | 是否跳过子 session（有 `parent_session_id`）的**自动**压缩；子代理只回传最终文本给父，中途压缩会丢早期工具证据导致失真传导。仅作用于自动压缩，手动压缩不受此配置影响（用户显式请求照做）（与 `[session.title].skip_child` 同模式） |

### [session.storage]

| 键 | 类型 | 默认 | 说明 |
|----|------|------|------|
| `busy_timeout_secs` | `u64` | `5` | SQLite busy_timeout（秒） |
| `max_connections` | `u32` | `5` | 连接池最大连接数 |

### [session.title]

| 键 | 类型 | 默认 | 说明 |
| ---- | ------ | ------ | ------ |
| `enabled` | `bool` | `true` | 是否启用自动生成标题 |
| `skip_child` | `bool` | `true` | 是否跳过子 session（有 `parent_session_id`）的标题生成；子任务 session 用 `parent_session_id` 表达归属，重命名反而扰乱父/子分组与前端过滤 |
| `snippet_max_chars` | `usize` | `500` | 输入截断长度（字符数），用户消息与 AI 回答各截取前 N 字符 |
| `max_len` | `usize` | `80` | 标题最大长度（字符数），超长截断加省略号 |

## [mcp]

全局 fallback：per-server 配置优先，此段提供默认值。

| 键 | 类型 | 默认 | 说明 |
| ---- | ------ | ------ | ------ |
| `tool_timeout_secs` | `u64` | `120` | 默认工具调用超时（秒） |
| `connect_timeout_secs` | `u64` | `60` | 默认连接超时（秒） |
| `max_backoff_secs` | `u64` | `60` | 最大退避时间（秒） |
| `max_reconnect_retries` | `u32` | `5` | 最大重连次数 |
| `max_initial_connect_retries` | `u32` | `3` | 最大初始连接重试次数 |
| `circuit_breaker_threshold` | `u32` | `3` | 熔断器触发阈值（连续失败次数） |
| `circuit_breaker_cooldown_secs` | `u64` | `60` | 熔断器冷却时间（秒） |
| `session_recovery_wait_secs` | `u64` | `15` | Session 恢复等待时间（秒） |

## [plugins]

| 键 | 类型 | 默认 | 说明 |
|----|------|------|------|
| `enabled` | table | `{}` | 插件开关，key=插件名；未列出默认启用 |

| 键 | 类型 | 默认 | 说明 |
| ---- | ------ | ------ | ------ |

## 完整示例

```toml
[models]
default = { model = "deepseek/deepseek-v4-flash", thinking_type = "enabled", reasoning_effort = "high" }
fast = { model = "deepseek/sensenova-6.7-flash-lite" }

[providers.deepseek]
name = "DeepSeek"
api_key_env_vars = ["DEEPSEEK_API_KEY"]
options = { base_url = "https://api.deepseek.com/v1" }

[providers.deepseek.models."deepseek-v4-flash"]
name = "deepseek-v4-flash"
reasoning_efforts = ["low", "medium", "high", "max"]
cost = { input = 2, output = 12.0 }
limit = { context = 128000, output = 8192 }

# 阶梯计费：cost.tiers 内联为数组，按 max_tokens 分区间计价
[providers.aliyun]
name = "阿里云百炼"
api_key_env_vars = ["DASHSCOPE_API_KEY"]
options = { base_url = "https://dashscope.aliyuncs.com/compatible-mode/v1" }

[providers.aliyun.models."qwen-max"]
name = "qwen-max"
cost = { tiers = [
    { max_tokens = 256000, input = 1.2, output = 7.2 },
    { max_tokens = 1000000, input = 4.8, output = 28.8 },
] }
limit = { context = 1000000, output = 65536 }

[mcp_servers.filesystem]
command = "npx"
args = ["-y", "@modelcontextprotocol/server-filesystem", "/tmp"]
enabled = true
tools = { bash = false }   # 禁用 filesystem 的 bash 工具

[mcp_servers.remote]
url = "https://${MCP_HOST}/mcp"
headers = { Authorization = "Bearer ${MCP_TOKEN}" }

[tools.runner]
max_concurrent = 8

[guard.loop]
tool_repeat_threshold = 4

[llm]
request_timeout_secs = 300
retry = { max_retries = 4294967295 }

[session.compression]
enabled = true
threshold = 0.85
keep_ratio = 0.05
keep_tokens_max = 8000
summary_max_tokens = 4096
fallback_context = 128000

[mcp]
tool_timeout_secs = 120

[engine]
input_channel_capacity = 64

[hooks]
timeout_secs = 5

[plugins.enabled]
loop_guard = true

[logging]
level = "info"
console = true
rotation = "daily"
```
