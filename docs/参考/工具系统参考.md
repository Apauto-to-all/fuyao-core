# 工具系统参考

> 10 个内置工具的完整参数定义与安全检查。API 签名见 `cargo doc --workspace`。

> **多 session 架构下的工具系统**：工具注册是**引擎级**（启动时装配一次，所有 session 共享同一份 `ToolRegistry`）；工具执行是 **session 级**（各 session task 在 ReAct 循环里自己查 handler 跑）。引擎**不为工具调用建全局队列、不排队、不协调**——多个 session 调同一工具，各自调用、各自拿结果，靠 session_id 标签区分不串话。详见 [工具系统设计](../解释/工具系统设计.md)。

## read — 文件读取 / 目录列表

| 参数 | 类型 | 必填 | 说明 | 默认 |
|------|------|------|------|------|
| `path` | string | 是 | 文件或目录路径 | — |
| `offset` | integer | 否 | 起始位置（文件=行号，目录=条目索引，从 1 开始） | 1 |
| `limit` | integer | 否 | 最大读取数量 | 500 |

安全：设备文件拒绝（`/dev/zero` 等 12 个）/ 框架内部路径（`.fuyao/.env`）拒绝 / 31 种二进制扩展名拒绝 / 重复读取去重 / 100k 字符上限 / 输出脱敏。文件不存在时建议相似文件名。

## write — 文件写入（完全覆盖）

| 参数 | 类型 | 必填 | 说明 | 默认 |
|------|------|------|------|------|
| `path` | string | 是 | 文件路径 | — |
| `content` | string | 是 | 完整内容 | — |

安全：`check_sensitive_path` 6 层检查（安全根目录 / 敏感前缀 / 系统文件 / 主目录文件 / 特殊文件名）/ 外部编辑检测 / 父目录自动创建。

## edit — 文件编辑（replace / patch）

| 参数 | 类型 | 必填 | 说明 | 默认 |
|------|------|------|------|------|
| `mode` | string | 是 | `replace` 或 `patch` | `replace` |
| `path` | string | replace 必填 | 文件路径 | — |
| `old_string` | string | replace 必填 | 要查找的文本 | — |
| `new_string` | string | replace 必填 | 替换文本 | — |
| `replace_all` | boolean | 否 | 替换所有匹配 | false |
| `patch` | string | patch 必填 | V4A 格式多文件补丁 | — |

安全：`check_sensitive_path` / 外部编辑检测 / 9 种模糊匹配策略（处理空白差异）。patch 模式逐操作检查敏感路径。

#### replace 模式模糊匹配策略

精确匹配失败时，依次尝试 9 种宽松策略（命中即停）：

| # | 策略 | 处理什么差异 |
|---|------|------------|
| 1 | exact | 精确匹配（基线） |
| 2 | newline_normalized | `\r\n` → `\n` |
| 3 | line_trimmed | 行首尾空白去除 |
| 4 | whitespace_normalized | 连续空白 → 单空格 |
| 5 | indentation_flexible | 忽略前导缩进 |
| 6 | escape_normalized | `\\n` → `\n` |
| 7 | trimmed_boundary | 首尾行空白处理 |
| 8 | unicode_normalized | 智能引号 / 全角字符 |
| 9 | block_anchor | 首尾行锚定 + 相似度（阈值 0.50 单匹配 / 0.70 多匹配） |

多匹配且未指定 `replace_all` → 报错提示提供更多上下文。

#### patch 模式（V4A 格式）

| 操作 | 说明 |
|------|------|
| Add | 创建新文件 |
| Update | hunk 匹配替换（有搜索行用模糊匹配，纯 `+` 行按 context_hint 插入或追加末尾） |
| Delete | 删除文件 |
| Move | 移动 / 重命名 |

逐操作执行，部分失败不中断，汇总错误。

|------|------|------|------|------|

## bash — 终端命令执行

| 参数 | 类型 | 必填 | 说明 | 默认 |
|------|------|------|------|------|
| `command` | string | 是 | shell 命令 | — |
| `timeout` | integer | 否 | 超时秒数（上限 6000） | 120 |
| `workdir` | string | 否 | 工作目录 | workspace |

安全：危险命令阻断（`rm -rf` / `dd of=/dev/sd*` / `mkfs.*` / fork 炸弹 / `curl|sh` / `shutdown` 等）/ workdir 白名单字符（挡 shell 注入）/ 环境变量屏蔽（12 类 API Key 前缀）/ 输出脱敏 / 超时杀进程组 / ANSI 清理 / 输出截断（头 40% + 尾 60%）。

多编码解码链：UTF-16 LE → UTF-8 → GBK(cp936, Windows) → lossy fallback，自动选择正确编码。

Shell 自动选择：Windows（git_bash > powershell > cmd）/ Linux·Mac（bash > sh）。

## webfetch — URL 抓取

| 参数 | 类型 | 必填 | 说明 | 默认 |
|------|------|------|------|------|
| `url` | string | 是 | URL（http/https） | — |
| `output_format` | string | 否 | `markdown` 或 `html` | `markdown` |
| `timeout` | integer | 否 | 超时秒数（上限 180） | 30 |
| `offset` | integer | 否 | 跳过字符数 | 0 |
| `limit` | integer | 否 | 返回字符数上限 | 100000 |

安全：SSRF 防护（私有网段 `10/8` `172.16/12` `192.168/16` `127/8` + 云元数据 `169.254.169.254` 等）/ DNS fail-closed / 跨域重定向提示（不自动跟随）/ 5MB 下载上限 / 缓存（TTL 900s，上限 100 条）。

重定向规则：同域（忽略 www 前缀）+ 同协议 + 同端口 + 无凭据 → 自动跟随；否则返回提示不跟随。缓存命中时直接返回，不重新请求。

| `name` | string | 否 | Skill 名称（不传则列出全部） | — |

## todowrite — 任务列表管理

| 参数 | 类型 | 必填 | 说明 | 默认 |
|------|------|------|------|------|
| `todos` | array | 否 | 任务数组（不传则读取当前列表） | — |

todos 元素：

| 子参数 | 类型 | 必填 | 说明 | 默认 |
|--------|------|------|------|------|
| `id` | string | 是 | 唯一标识 | — |
| `content` | string | 是 | 任务描述 | — |
| `status` | string | 否 | 状态 | `pending` |

status 枚举：`pending` / `in_progress` / `completed` / `cancelled`。

规则：顺序=优先级，同时只能一个 `in_progress`。按 session_id 隔离持久化。

## subagent — 子代理派生

| 参数 | 类型 | 必填 | 说明 | 默认 |
|------|------|------|------|------|
| `subagent_type` | string | 是 | 子代理定义名（系统提示词「子代理」索引列出的 name，如 `researcher` / `executor`） | — |
| `description` | string | 是 | 3-5 词任务描述（供追踪显示） | — |
| `prompt` | string | 是 | 给子代理的完整任务指令（应自包含所有必要上下文） | — |

派生一个带 `parent_session_id` 的子任务 session，跑完整 ReAct 循环（可调工具），同步等最终回复回喂父 ReAct。子代理用 `Fresh` 模式创建——空上下文，**不继承父会话历史**，故 `prompt` 必须自包含必要上下文。

`subagent_type` 决定子代理的人格：透传为子 session 的 `AgentConfig.definition`，引擎按名加载 `agents/{subagent_type}.md`（含 mode 校验，须为 `subagent` 或 `all`）。可选值见主 Agent 系统提示词中的「子代理」索引层（内置 `researcher` / `executor` + 用户自定义，用户同名文件覆盖内置）。

安全 / 边界：

- **递归防护**：本工具标 `child_invisible = true`，对子 session 隐藏——子代理不能再派生子代理（LLM 看不到此工具就不会调）
- **超时兜底**：600s 无最终回复强制 `end_session` 退出，防子 session 卡死阻塞父 ReAct
- **生命周期事件**：派生时发 `ChildSession(Started)`、结束时发 `ChildSession(Ended)`，前端据此开辟 / 关闭子代理渲染区
- **中间事件透传**：子 session 的 Chunk / ToolCall / ToolResult 经父 session 出站通道进 fan_out（`session_id` 标 child），前端按 `child_session_id` 实时渲染进度
- **取消响应**：监听父取消令牌，被取消时立即 `end_session` 并返「被父取消」
- **失败降级**：派生失败 / 发送失败 / 超时 / 空回复均返可读错误字符串（如 `❌ 子代理派生失败：xxx`），不抛异常
